# 📌 Overview

Finding a rental property is easy.

**Finding the right rental property is not.**

A user may have to search through dozens of listings, compare different
rents, evaluate property conditions, understand whether a property fits
their requirements, and negotiate with an owner or agent.

RentLens was built to bring these steps together.

Instead of acting as only a property-search application, RentLens acts as
a **rental decision-support platform**.

The application combines:

- Property discovery
- Structured rental data
- Gemini AI
- Gemini Vision
- Property analysis
- Contextual AI assistance
- Property comparison
- Negotiation assistance
- User authentication
- Search history
- Rental analytics

into a single Streamlit application.

---

# 🎯 Problem Statement

Traditional rental-property searching creates several problems:

### 1. Too many listings

Users can find hundreds of properties but struggle to identify the most
relevant ones.

### 2. Difficult comparison

Important information such as rent, area, BHK, furnishing, and property
type is often spread across different listings.

### 3. Limited property understanding

A listing may contain an image that gives useful information about the
condition of a property, but users generally have to evaluate it manually.

### 4. Lack of contextual assistance

Generic AI assistants do not automatically understand what properties the
user searched for.

### 5. Negotiation uncertainty

Users may not know how to approach an owner or what aspects of a rental
agreement they can discuss.
